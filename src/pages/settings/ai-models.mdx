# AI &amp; Pipeline

**Settings → Catalog &amp; content → Product writing** opens the **AI &amp; Pipeline** page. It holds the AI key, shows which AI engines ThreadCloud runs, and sets how product copy is written. It also carries the pricing, purchase order and receiving defaults.

<div class="callout callout-info">
<div class="callout-title">Last verified against the app: 2026-10-01</div>
If a section or field here doesn't match the app, it changed and this page is stale. Tell the team.
</div>

<div class="callout callout-danger">
<div class="callout-title">Owner territory</div>
Changes here affect every product ThreadCloud writes. Only the store owner should change them. Only the Shopify account owner can test, replace or clear the AI key.
</div>

Use the search box at the top (for example "MSRP", "brand voice", "FX lock") to jump to a setting. Each section opens and closes with its heading.

## Technical controls

### The API key

The store's own AI key. It is stored encrypted and never shown again after saving. It reads **Key configured** once saved.

<ol class="steps">
  <li>Get a key from your AI provider. For Anthropic, keys start with <code>sk-ant-</code>.</li>
  <li>Click <strong>Replace API key</strong> and paste it. Leaving the field blank keeps the key you have.</li>
  <li>Save.</li>
</ol>

<div class="callout callout-info">
<div class="callout-title">Which provider</div>
Anthropic is required for reading photos and images. Description writing also works with OpenAI or Google keys. AI usage is billed to your own account; ThreadCloud does not mark it up.
</div>

### AI Engines

A panel lists the engines and the model each one runs. The status at the top reads **Operational**, or **No API key**.

| Engine | What it does |
|---|---|
| **Parse** | Reads PDFs, linesheets and images |
| **Swatch** | Reads swatch and colour cards |
| **Enrich** | Pulls structured product facts |
| **Describe** | Writes the customer-facing description |
| **Brand Research** | Heritage and provenance for the brand record |

ThreadCloud chooses these models and updates them after testing on real orders. You don't pick models any more. The dot beside an engine pulses while it is working.

## Build &amp; Parse controls

### MSRP Pricing

| Field | What it does |
|---|---|
| **MSRP Multiplier** | Landed cost × multiplier = suggested retail price |
| **Round MSRP to nearest** | Rounds the suggested price up to the nearest dollar amount |
| **Prices end in** | One digit, 0 to 9. When set it replaces the round-up and only ever moves a price up. Leave blank for no ending. |

**Storefront size guide** links to the size conversions your filters use. See [Storefront](/settings/theme/#size-guide).

## Enrich

How ThreadCloud writes product descriptions on the Enrich tab.

### Brand Voice

| Field | What it does |
|---|---|
| **Tone and style** | How the copy should sound. Used in every description. |
| **Output structure** | What to include, in order, one per line |
| **Creativity** | **Low** (focused, consistent), **Balanced**, or **High** (creative, varied) |
| **Words and phrases to avoid** | Words the writer will never use |

**Technical writing rules** (folded) holds advanced instructions for the description writer. Leave them to ThreadCloud unless asked.

Click **Save writing settings**. Changes apply to new and regenerated descriptions. Existing descriptions stay as they are until regenerated on Enrich.

### Product description appendix

| Field | What it does |
|---|---|
| **Fit advice** | The "Fit:" line per fit. Leave a field empty for the default. |
| **Fine print by stock type** | A small note at the foot of the description, chosen by the product's stock type |
| **Show the supplier "Style:" code on the product page** | When off, the supplier's article, model and colour code stay internal and are not printed for shoppers |

Click **Save appendix**.

### Occasions, category mappings and always-in-stock tags

- **Occasion Taxonomy**: the occasions your store uses, each with a short definition so ThreadCloud can classify products.
- **Category Mappings**: how your own product types map to ThreadCloud categories.
- **Always in stock**: the Shopify tags that mark NOS products, for example `nos, core, carryover`.

## Purchase Orders

- **Require ship and cancel dates on purchase orders**
- **Default ship window (days)**: days between the order date and the expected ship date

## Receiving

- **FX Rate Lock**: the exchange rate locks automatically on an order's first receipt. Locked rates are never recalculated.
- **Measurement Baselines**: how many categories have measurement ranges set from receiving.

## Saving

**Save settings** saves the page. **Reset to defaults** puts every field back to ThreadCloud's defaults.

## Common patterns

### After changing the brand voice

1. Save the new voice.
2. Open an order's **Enrich** tab and regenerate the descriptions you want in the new voice.
3. Push those products again to update Shopify.

### When the AI is down or slow

If your provider's status page shows an incident, don't change the key. Parse and Enrich wait and retry on their own. If it lasts more than 30 minutes, see [If something breaks](/runbook/).

## Common mistakes

<div class="callout callout-warn">
<div class="callout-title">A wrong key</div>
ThreadCloud doesn't call your provider when you save, so a wrong key only shows the next time ThreadCloud reads a linesheet or writes copy. After changing the key, read one small linesheet to check it. The <strong>AI engines</strong> tile in <a href="/settings/store-health/">Settings</a> shows if runs are failing.
</div>

<div class="callout callout-warn">
<div class="callout-title">Changing the voice without testing</div>
Try a voice change on a few styles before regenerating a whole order.
</div>
