# First-time setup

Everything from installing ThreadCloud to a fully-enriched catalog with working storefront filters. The in-app wizard is three quick screens plus a finishing screen and takes about two minutes; enriching your existing catalog afterwards is where the time goes — and where the payoff is.

<div class="callout callout-info">
<div class="callout-title">Last verified against the app: 2026-07-10</div>
If a screen or button name here doesn't match the app, it changed and this page is stale — tell the team.
</div>

<div class="callout callout-info">
<div class="callout-title">Who does this</div>
The store <strong>Owner</strong> runs first-time setup — it installs metafield definitions and authorises Shopify access. You only do it once per store. Progress is saved on the server as you go, so closing the tab and coming back later resumes exactly where you left off — it doesn't reset.
</div>

## Before you start

- A Shopify store you own (Partner-approved or live).
- Owner access to that store.
- Optional but recommended: an Anthropic API key (for AI descriptions + linesheet parsing). You can add it during setup or later.

## Install from the Shopify App Store

Install ThreadCloud like any Shopify app. On first open it asks you to approve the access scopes (read + write products and metafields). Approve, and the wizard opens full-screen in place of the dashboard.

## Screen 1 — Welcome

The opening screen explains what ThreadCloud unlocks: <strong>Smart Filters</strong> (storefront facets), <strong>Buy Analytics</strong> (OTB, blended margin, brand scorecards, sell-through), and <strong>58 structured data points</strong> per product. One button: <strong>Begin setup</strong>.

<strong>What the button does:</strong> installs the metafield definitions and authorises ThreadCloud to read and write product metafields, then automatically — no separate steps for you to run — pulls your store's name, currency, and timezone from Shopify (only filling in values you haven't already set yourself), provisions the storefront filter token, seeds the standard set of delivery-window templates, and scans your active catalog for the brands and product types already in it. No existing product data is touched.

<div class="callout callout-warn">
<div class="callout-title">If setup doesn't complete</div>
If the screen doesn't advance, or filters don't show up later, re-open the app — Screen 1 is safe to re-run. Persistent failure → [If something breaks](/runbook/).
</div>

## Screen 2 — Your rack

A green banner confirms what setup just did automatically (store name, currency, delivery-window count, "storefront filters connected"), then shows the brands ThreadCloud detected in your catalog as tap-to-toggle chips — all selected by default. Tap one to leave it out for now.

<strong>What the buttons do:</strong> <strong>Confirm & continue</strong> creates a brand record for each selected vendor and seeds the enrichment queue for your catalog. <strong>Skip for now</strong> moves on without creating any brands — do this and set brands up later from Brand Registry if you'd rather not decide chip-by-chip during setup.

<div class="callout callout-tip">
<div class="callout-title">Bulk-importing a large supplier registry</div>
The wizard itself is chip-by-chip. If you have a big existing supplier list to load in one shot, skip this screen and use the CSV import in <strong>Settings → Brands & Suppliers</strong> instead — same bulk-import tool the old wizard used, just moved out of the setup flow.
</div>

## Screen 3 — The engine

Paste your Anthropic API key to unlock AI descriptions and linesheet parsing. Get a key at <strong>console.anthropic.com</strong> — they start with <code>sk-ant-</code>.

<div class="callout callout-info">
<div class="callout-title">Billing</div>
AI usage is billed to <strong>your</strong> Anthropic account. ThreadCloud does not mark up or charge for AI calls. Add or change the key anytime in [Settings → AI & Models](/settings/ai-models/).
</div>

<strong>What the buttons do:</strong> <strong>Switch it on</strong> validates the key looks right and saves it. <strong>I'll add it later</strong> skips it — the rest of ThreadCloud works without it; you just won't get AI descriptions or auto-parse until it's set.

## Finishing screen — your store is dressed

A short celebration screen with a checklist of what setup just did (delivery windows, brands, catalog classifying, metafields). One button: <strong>Enter ThreadCloud</strong>.

<div class="callout callout-info">
<div class="callout-title">This click is what finishes setup</div>
Setup isn't marked complete until you click <strong>Enter ThreadCloud</strong> on this screen — that's deliberate, so you see the celebration instead of getting bounced straight to the dashboard.
</div>

## After the wizard: enrich your existing catalog ⭐

This is the step that turns a freshly-installed store into a working one: every existing product gets a category, colour group, fabric, country, and the metafields that drive storefront filters. The wizard already seeded the queue when you confirmed your brands on Screen 2 — you finish it on the Legacy Enrichment page.

You land on the dashboard with a <strong>"Setup complete — enriching legacy products in background"</strong> banner, and a persistent <strong>catalog enrichment</strong> banner appears whenever the queue has work. Click it, or open [Settings → Legacy Enrichment](/settings/legacy-enrichment/).

### The fast path (clean catalog)

1. Open <strong>Settings → Legacy Enrichment</strong>.
2. Classification may already be running from setup — if not, click <strong>Run Classification</strong> and watch the ambient bar finish. You can navigate away while it runs.
3. Open the <strong>Ready</strong> tab → <strong>Apply Selected</strong>. Filters go live on the storefront.

### The review path (mixed metadata)

1. Open the <strong>Needs Review</strong> tab — these rows are missing a field, not wrong. Most just need a Colour Group or Pattern set.
2. For each row, either click the inferred values to <strong>Confirm as-is</strong>, or set the missing field and save. Use <strong>bulk edit</strong> to set the same value across many selected rows at once.
3. Then <strong>Apply Selected</strong>.

<div class="callout callout-info">
<div class="callout-title">"Needs Review" does not mean the AI was wrong</div>
It means a field is missing or low-confidence. Confirming as-is is one click. The full per-tab walkthrough lives on [Settings → Legacy Enrichment](/settings/legacy-enrichment/).
</div>

<div class="callout callout-tip">
<div class="callout-title">Rough timing</div>
About 5 min for 500 products, 20 min for 2,000, 50 min for 5,000 — classification plus apply, at parallel speed.
</div>

## What to check when you're done

<div class="callout callout-info">
<div class="callout-title">Verification checklist</div>
- A sample product in Shopify admin has <code>tc_core.category</code> populated.
- The storefront shows smart-filter facets with real values.
- Settings → Legacy Enrichment <strong>Applied</strong> tab shows your catalog.
- The settings dashboard's Legacy Enrichment tile shows a live count.
- (If you set an API key) a new Build Order parses and enriches.
</div>

## Common issues

<div class="callout callout-warn">
<div class="callout-title">"Switch it on" or descriptions do nothing</div>
No Anthropic key set. Add it in [Settings → AI & Models](/settings/ai-models/).
</div>

<div class="callout callout-warn">
<div class="callout-title">Classification looks stalled</div>
It runs in the background and the ambient bar shows progress — you can leave the page. If counts never move, re-open Legacy Enrichment; persistent issues → [If something breaks](/runbook/).
</div>
